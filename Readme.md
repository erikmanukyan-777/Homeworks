# Innovation Diffusion Analysis: WHOOP MG

This project analyzes the global adoption and diffusion of the WHOOP MG (featured in TIME’s Best Inventions of 2025) by utilizing historical adoption data from early fitness trackers (Fitbit) and estimating the Bass Diffusion Model parameters.

# Structure

- `data/` 
  - `dataset1.csv`: Historical time-series dataset containing active user adoption numbers for Fitbit (2012–2025).
- `img/` 
  - `image1.png`: Created plot which shows the Bass model fit and adoption forecast curves.
- `report/` 
  - `report.pdf`: The final report in PDF format.
  - `report_source.md`: The source markdown file used to generate the report.
- `script1.py`: Python code for parameter estimation (`scipy.optimize.curve_fit`), Bass model calculations, and adoption forecasting.
- `README.md`: Project documentation.
